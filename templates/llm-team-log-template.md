# LLM Team Log

Report as results, not as an appendix afterthought:
- Roles used + prompts version
- Search: per source — string, date, hits, retrieved, status (searched / partial / blocked / not run) + retry history
- Screening: agreement rate, Cohen's kappa (3-category + binary) + explanation, disagreement counts by type, adjudication outcomes, items flagged for the human author + their decisions
- Extraction: fields compared, discrepancy count + rate per field, substantive discrepancies + how each was settled
- Risk of bias: disagreement counts by domain + settlement route
- Statistics: hand-check record (which pool, second route, result)
- Visual QA: page-by-page inspection log + failures + fixes
- Corrections after first build: every one, dated
- Incidents: blocked sources, retrieval failures, arithmetic breaks — kept visible
