# Manuscript Shipping Checklist

- [ ] Structured abstract < 1,000 words, Cochrane order
- [ ] Plain-language summary
- [ ] Summary of Findings BEFORE Background, GRADE reasons per outcome
- [ ] Every difference between protocol and review declared
- [ ] Every pooled number traced in claims-verification-log.md to results-summary.csv + settled extraction
- [ ] Every forest plot: summary diamond + prediction interval, page-fit checked
- [ ] Every figure/table page rendered + visually inspected, log signed
- [ ] PRISMA arithmetic reconciles exactly
- [ ] Registration stated plainly (number only if actually issued)
- [ ] No clinical / medication recommendation
- [ ] Funding + conflicts + factual AI-assistance note (RAISE 2025)
- [ ] 'Cochrane-level, not a Cochrane review' stated
- [ ] Plain-writing pass done
